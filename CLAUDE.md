# Don't edit this repo

This public repo is the **built** website that GitHub Pages serves for
masterscope.gwstudio.com.au. It is generated by the publish workflow in the private repo
**grantelliotwalker-coder/MasterScope-Source**, which holds the sources (`_src/`), the build,
the notes and all of Grant's Decisions. Read that repo's `CLAUDE.md` first.

- Change pages, styles, the analyser or anything built: edit `_src/` in MasterScope-Source and push there. The workflow rebuilds and publishes here. Anything you edit here directly is overwritten on the next publish.
- The only things edited here directly: images in `img/`, installers in `downloads/`, and the workflows `release.yml` and `indexnow.yml`.
- Never add sources, notes, `_src/` or a `CLAUDE.md` with decisions to this repo: it is public.
