Before you report a bug

  • Check you have the latest version. The current version is 1.0.3; Liminal shows its version in the About box (the ⓘ button), and every installer has the version in its file name. Downloads are on the Liminal and Meter pages.
  • Look in the troubleshooting section of the Liminal guide: it covers plug-ins that don't show up, the install warnings on Windows and Mac, and Open in MasterScope.
  • Attach what you can. A screenshot, or the report Liminal saved in Documents › MasterScope, helps us see exactly what you saw. Your audio is never needed.

What happens next

We reply as soon as we can. Fixes and new features arrive in new versions: see What's new for each release. Your email address is only used to reply to you.
